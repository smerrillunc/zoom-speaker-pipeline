# File formats

All files are UTF-8 JSON. `<id>` is the video's file name without its extension.

## `ocr.py` → `<id>.ocr.json`

| Field | Meaning |
|---|---|
| `video` | source file name |
| `duration` | seconds |
| `sampling_rate` | frames read per second of video |
| `super_resolution` | whether EDSR re-reads were enabled |
| `frames_sampled` | frames inspected |
| `frames_named` | frames where a name was read |
| `frames_grid` | frames where the highlight ring was found |
| `frames_overlay` | frames named from the screen-share corner thumbnail instead |
| `raw_speaker_changes` | `[[seconds, raw OCR string], ...]`, one entry each time the read changes; `"No Speaker"` when nothing was read |
| `video_seconds` | wall time of the step |

Files named `<id>.video.json` from earlier versions have the same fields and are
accepted by `clean_ocr.py`.

## `transcribe.py` → `<id>.asr.json`

| Field | Meaning |
|---|---|
| `segments` | `[{"start", "end", "text", "speaker"}]`; `speaker` is a pyannote voice cluster (`SPEAKER_03`), absent when unclustered |
| `clustered` | whether voice clustering ran |
| `error` | why clustering failed, or `null` |
| `asr_seconds` | wall time of the step |

## `clean_ocr.py` → `<id>.speakers.json`

| Field | Meaning |
|---|---|
| `meeting`, `video`, `duration` | as above |
| `changes` | `[[seconds, speaker], ...]`: the cleaned on-screen track. `speaker` is the collection-wide identity key, or `"Other"` for no name, a room, a device or an organisation tile |
| `speakers` | `{speaker: {"display", "seconds_on_screen"}}` |
| `stats` | frame counters, `grid_fraction`, `named_fraction`, `layout` (`gallery` ≥ 0.8 > `mixed` ≥ 0.3 > `screen-share`) |

## `clean_ocr.py` → `registry.json` (one per collection)

| Field | Meaning |
|---|---|
| `version`, `parameters` | code version and every setting that affected the result |
| `meetings` | meeting ids in the collection |
| `label_kinds` | how many raw reads parsed as `person`, `device`, `role`, `runon` (the crop caught on-screen text) or `noise` |
| `merges` | cross-meeting merges per rule |
| `identities` | one per person: `speaker` (key), `display`, `seconds` on screen, `meetings`, `titles`, `roles`, and `variants` |
| `identities[].variants[]` | `key`, `seconds`, `meetings`, the most common displayed `names`, and for a merged variant the `rule`, `score` and `via` (the key it was merged into) |
| `refused` | links a rule proposed but a guard refused: `kept_apart`, `rule`, `reason` (`ambiguous: N candidates`, `both on screen in the same meeting`, `cluster names disagree`) |

To undo a merge, drop the variant from its identity and map its key back to itself.
Transcripts are regenerated by `merge.py` in seconds.

## `merge.py` → `<id>.json` (the transcript)

`[{"start": float, "end": float, "speaker": str, "text": str}]`, with consecutive
segments of one speaker joined into turns. `speaker` is the identity key from
`registry.json`. Keys are lowercase ASCII with titles, roles, punctuation and middle
initials removed: "Judge Patricia O'Caña-Olivarez" → `patriciaocanaolivarez`.

## `merge.py` → `<id>.attribution.json`

| Field | Meaning |
|---|---|
| `version`, `parameters` | as above |
| `display_names` | `{speaker: display name}` for every speaker in the transcript |
| `turns[]` | parallel to the transcript: `source` (`cluster`: named with its voice cluster; `screen`: at least one segment named from the screen inside a mixed cluster), `screen_share` (share of the turn the chosen name covered on screen), `segments`, `screen_segments`, `clusters` |

## `merge.py` → `<id>.stats.json`

The `stats` from `<id>.speakers.json`, plus `duration_minutes`, `turns`, `turns_named_from_screen`,
`speakers`, `audio_clustering`, `clustering_error`.
